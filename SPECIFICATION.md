SPECIFICATION.md - AutoClip Local1. Ikhtisar ProyekAplikasi web lokal yang menerima video panjang, mentranskripsinya, mencari momen paling menarik (berdasarkan teks), dan memotongnya menjadi format vertikal (9:16) dengan subtitle otomatis. Sistem ini dirancang berjalan secara mandiri di perangkat keras lokal (minimal RAM 16GB dan GPU) tanpa batasan limit (rate-limit eksternal untuk pemrosesan utama).2. Hak Akses Pengguna (User Access Rights)Karena aplikasi ini difokuskan sebagai portofolio dan berjalan secara lokal (on-premise), arsitektur dasarnya dirancang untuk Single-User/Local Admin.Peran PenggunaHak Akses Logika & FiturKeteranganLocal Admin (Owner)Akses penuh ke seluruh direktori sumber lokal.Memiliki hak membaca local storage untuk mengunggah video.Local Admin (Owner)Hak penuh manajemen API Key pihak ketiga.Dapat memasukkan/mengganti kunci API Pexels di file .env.Local Admin (Owner)Manajemen Garbage Collection & Storage.Hak otomatis untuk menghapus file temporary via sistem backend.Local Admin (Owner)Akses ke seluruh riwayat pembuatan klip.Dapat melihat, memutar ulang, dan mengunduh hasil di UI.3. Spesifikasi Fitur UtamaA. Manajemen Sumber & ProyekSumber Video (YouTube): Menerima input URL YouTube dan melakukan pengecekan kualitas sebelum diunduh.Sumber Video (Lokal): Menerima unggahan video langsung dari perangkat pengguna.Struktur Folder: Sistem wajib menggunakan Judul Proyek sebagai nama folder penyimpanan agar struktur output rapi.Riwayat Pembuatan: Sistem memiliki log riwayat (history) untuk melihat kembali klip yang sudah pernah diproses.Checkpoint Engine: Dilengkapi State Machine (UPLOADED, AUDIO_EXTRACTED, TRANSCRIBED, ANALYZED, RENDERED) agar pemrosesan yang terputus bisa dilanjutkan dari titik terakhir tanpa mengulang dari awal.B. Pemrosesan AI & AnalisisTranskripsi Super Presisi: Menggunakan Whisper by OpenAI versi lokal untuk menghasilkan transkrip dengan word-level timestamps yang sangat akurat.Analisis Cerdas (LLM): Menggunakan Ollama secara lokal untuk membaca transkrip penuh dan mengekstrak momen menarik.Output LLM: LLM menentukan durasi klip (auto) dan merangkum analisis engagement tinggi beserta alasannya ke dalam format JSON yang terstruktur.Anti-Halusinasi (Data Handoff): LLM hanya menggunakan ID Kalimat/Kata sebagai acuan pemotongan, bukan memprediksi angka waktu (timestamp) secara mandiri.C. Mesin Rendering & Pengeditan VisualPemotongan Otomatis: Fitur center-crop statis untuk memastikan fokus video berada di tengah.Pilihan Aspek Rasio: Output dapat disesuaikan dengan kebutuhan pengguna, mencakup rasio 9:16, 16:9, 4:5, dan 1:1.Kualitas Unduhan: Pengguna dapat mengunduh video klip hasil akhir (resolusi dipertahankan dari sumber).D. Sistem Subtitle EkstensifMode Tampilan Teks: Menyediakan opsi kemunculan teks secara word-by-word atau standar kalimat penuh.Variasi Jenis Huruf: Pengguna dapat mengatur Font Family (jenis huruf), Font Size (ukuran huruf), dan Font Weight (ketebalan).Gaya Tambahan: Menyediakan dukungan untuk Text Styling seperti huruf besar semua (uppercase).Warna Sorotan: Mampu mengaplikasikan Highlight Color pada kata yang sedang diucapkan.E. Integrasi Media DinamisDynamic B-Roll (Pexels API): LLM menerjemahkan konteks kalimat ke pencarian Pexels untuk menyisipkan video ilustrasi secara otomatis.Arsitektur Fallback B-Roll: Dirancang sebagai Non-Blocking Overlay.Keandalan Rendering: Jika Pexels API mengalami timeout atau gagal, rendering tetap berjalan menggunakan video center-crop asli.4. Standar Infrastruktur (The Pro Stack)Antrean Pemrosesan (Queueing): Hanya diizinkan satu model AI berat berjalan di memori (VRAM/RAM) pada satu waktu (FFmpeg -> Whisper -> Ollama).Manajemen Ruang Penyimpanan: Memiliki fitur Garbage Collection yang secara otomatis menghapus file temporary (seperti audio ekstraksi .wav mentah) segera setelah status proyek berubah menjadi RENDERED.Isolasi Dependensi: Proyek ini wajib menggunakan Virtual Environment (venv atau conda) dengan pembagian requirements.txt terpisah antara ekosistem web (FastAPI, MoviePy) dan AI (PyTorch, Whisper).
